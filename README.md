# mangaReader

A simple manga reader website where users can upload comic pages (images) and read them in the browser.

## Usage

1. Open `/home/runner/work/mangaReader/mangaReader/index.html` in a browser.
2. Click **Upload pages** and select one or more comic image files.
3. Use **Previous** and **Next** to read through pages.

No backend is required; files are loaded locally in the browser.
